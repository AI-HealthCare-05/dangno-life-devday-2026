# 로컬 앱 최신화 — 2026-10-15

기존 `local-develop`의 계정 재화·챌린지·사진 인증 변경을 유지하고 2026-10-13에 배포용 앱에서 검증한 숲 수정 사항을 반영했다. Git 원격 병합이나 배포 서버 업데이트는 수행하지 않았다.

## 반영 사항

- 입장 인증으로 확인한 계정 표시 이름을 게임과 렌더러에 최초부터 적용한다. 캐릭터 위 이름은 카메라의 오래된 별칭보다 게임 상태의 이름을 우선하며, 일시적인 계정 조회 실패 때 기존 이름을 유지한다.
- 창고의 기존 회전·배치 확정·취소 버튼을 숨겨진 옛 메뉴에서 게임 프레임으로 옮긴다. 위치 선택 전에는 확정을 비활성화하고, 선택 후에는 터치할 수 있다. 취소하면 이동 패드를 복구한다.
- 전축 이미지가 없을 때 누락 텍스처를 만들지 않으며 집 안에서만 표시한다. 기존 로컬 전축 이미지를 유지해 APK에 포함했다.
- 모바일 캔버스는 디스플레이 배율을 1~2배 범위로 반영하고 최대 변 4096픽셀을 유지한다. 당근밭 표시 레이어는 첫 당근밭 진입에서 생성하고 재사용한다.
- 서비스워커 캐시를 `v185-boot-placement-memory`로 갱신했다. 계정 지갑 코드를 유지했다.
- 오늘이 XAI 기준 manifest와 비공개 기준표본은 로컬 서버의 기존 검증된 구성을 유지한다. 모델·기준표본·SQLite DB는 APK에 포함하지 않았다.

## 검증·설치

- 관련 Node 테스트 100개, 실제 브라우저 배치 UI 테스트 1개 통과. 재화·챌린지 응답의 중복 보상 방지 회귀 검증을 포함한다.
- 로컬 모바일 번들 생성, Capacitor 동기화와 Android `assembleDebug` 성공. 공유 Gradle 설정의 배포 옵션과 혼동하지 않도록 `-PmobileDeployment=false`를 명시했다.
- APK 패키지 `life.dangno.app`, API `http://127.0.0.1:8000`, 기존 디버그 서명 일치를 확인했다.
- 블루스택 기존 로컬 APK를 보관하고 `install --no-streaming -r`로 업데이트했다. 첫 스트리밍 설치는 응답 없이 실패했으며, APK를 먼저 복사하는 방식은 성공했다. 기존 앱을 제거하거나 데이터를 초기화하지 않았다. 배포용 패키지는 변경하지 않았다.
- 설치 후 실제 WebView에서 로그인 유지, 로컬 API 주소, `/api/v1/ready` 200, 숲 초기 계정 이름 일치, 누락 텍스처 0개, 전축 숨김, 당근밭 레이어 지연 생성을 확인했다.
- 블루스택 720×1256 CSS 화면·DPR 1.5에서 캔버스는 1080×1884였다. 프레임 측정은 짧은 관찰이며 FPS 개선이나 전체 메모리 감소를 입증한 것으로 취급하지 않는다.
- 실제 창고 위치 선택 후 회전·확정·취소 버튼이 활성화되고 화면 내 터치 가능함을 확인했다. 확정 저장은 하지 않고 취소했으며 전후 숲 저장 해시가 동일했다. 업데이트 설치 전후 저장 해시도 동일했다.
- 로그인된 기존 계정의 오늘이 XAI 조회에서 `approved`, 표시 허용·SHAP true, 선택 요인 3개, 전체 그래프 9개와 `complete=true`를 확인했다. 분석·건강정보·보상 기록을 새로 만들지 않았다.

검증 APK는 상위 작업 폴더의 `outputs/local-update-20261015/gandang-local-latest.apk`에 있다. 동일 폴더에 복원용 기존 APK와 상태·검증 메타데이터를 보관했다. 휴대폰은 연결되지 않아 이번 설치 대상은 블루스택이다.
