# 의료기관 목록 더보기

일반 의료기관 검색은 처음 최대 5곳을 거리순으로 표시하고, ‘더보기 (현재 표시 수/전체 수)’를 누르면 아래에 최대 5곳씩 추가한다. 한 열로 세로 확장하며 기존 카드를 다시 생성하거나 다른 페이지로 이동하지 않는다. 메인·인트로 화면의 일반 의료기관 검색에 적용한다.

수신한 검색 결과 안에서 확장하므로 더보기 클릭은 추가 위치 요청이나 API 호출을 발생시키지 않는다. 모두 표시하면 버튼은 숨긴다. 5곳 이하이면 처음부터 버튼을 숨기며, 새 검색·검색 실패·빈 결과·개발용 응답에서는 이전 목록과 버튼이 남지 않는다. 지도에는 기존처럼 검색된 전체 기관을 표시한다. 응급의료기관 조회는 이번 변경 대상이 아니다.

검증: `scripts/mobile/check-diagnosis-guidance.mjs`에서 12곳을 5→10→12곳으로 세로 확장, 기존 카드 유지, 추가 조회 없음, 6곳 마지막 묶음·5곳·빈 결과와 검색 초기화를 확인한다.
