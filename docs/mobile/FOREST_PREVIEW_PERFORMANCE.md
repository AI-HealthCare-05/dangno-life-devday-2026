# 당근의 숲 메뉴·장면 전환 성능 개선

2026-10-09. 앞선 먹이주기 개선과 별도로, `FOREST_LAG_AUDIT_20261009.md`에서 제안한 네 가지 개선을 적용했다.

## 변경 사항

- 꾸미기 창의 120ms 애니메이션 갱신에서 상품 썸네일 합성을 제거했다. 카테고리·선택 항목·이미지 준비 상태가 바뀔 때만 상품 그림을 갱신한다. 큰 미리보기와 펫 애니메이션은 유지한다.
- 저장 코디와 모임 얼굴은 현재 표시 중인 목록에서만 그린다. 숨겨진 옷장·창고·모임 패널은 이미지 로딩 완료 시에도 다시 합성하지 않는다.
- 동일한 아바타 그림은 공통 LRU 캐시에서 재사용한다. 키에 의상·성별·포즈/프레임·자산 버전·이동수단 미리보기·그림 크기와 범위를 포함한다. 변경된 의상이나 나중에 로드된 레이어는 다시 합성한다. 정지 아바타의 큰 미리보기는 프레임 0을 재사용하고 펫은 별도로 움직인다.
- 캐시에 유지하는 캔버스의 픽셀 버퍼 합계는 4MiB 이하로 제한하고, 오래된 항목을 제거할 때 캔버스 버퍼도 해제한다. 이는 캐시 버퍼 제한이며 전체 앱 메모리 사용량을 뜻하지 않는다. 계정·코디·재화 저장소는 변경하지 않는다.
- 집·당근밭 이동에서 `renderInventory()`를 제거했다. 배치 선택 해제·장면·음악·수확 표시만 갱신한다.
- 이미지 로딩 이벤트는 프레임당 하나로 묶어 표시 중인 미리보기만 갱신한다. LPC 준비 이벤트/Promise의 중복 갱신을 제거했다. 백그라운드에서 멈췄던 화면은 복귀 시 갱신한다.
- LPC·개별 가구·오리 자산을 병렬로 준비한다. 세 가지 준비가 모두 끝난 뒤 화면을 공개하므로 잘린 구형 가구가 잠깐 나타나는 현상을 다시 도입하지 않는다.

## 검증

`tests/forest-preview-performance.test.cjs`는 캐시 재사용/무효화, LRU 버퍼 제한·해제, 이미지 이벤트 병합, 닫힌 화면 생략, 장면 전환의 배치·음악 유지, 정지 미리보기와 펫 애니메이션 분리, 모든 자산 준비 후 공개를 검증한다. 기존 가구 계약 테스트는 병렬 대기 구조에 맞춰 갱신했다.

S25 설치본은 기존 `life.dangno.app`의 네이티브 바이너리·디버그 서명을 유지하고 최신 로컬 웹 번들을 교체한 검증용 APK이다. API는 `http://127.0.0.1:8000`이고 ADB reverse를 사용한다. `life.dangno.app.deployment`는 변경하지 않는다. 전체 Gradle 재빌드나 배포용 서명 검증으로 간주하지 않는다.

동일한 S25 로컬 앱에서 클릭 처리 및 다음 애니메이션 프레임까지의 지연을 비교했다. 다음 프레임 지연은 전체 GPU 렌더 완료 시간이나 화면 주사율 측정과 다르다. 이전 자료는 덮어쓰지 않고 `outputs/mobile/*-after.json`에 별도로 보관했다. 개인정보·토큰·건강정보 원문은 기록하지 않는다.

### 남아 있는 최초 합성 비용

보이지 않는 그림을 미리 만들지 않으므로, 새 의상 카테고리나 모임을 처음 열 때는 합성이 필요하다. 전체 카테고리를 순회한 검사에서는 새 머리/상의 목록이 약 0.65–0.72초, 저장 코디가 약 0.88초, 모임이 약 0.80초였다. 같은 모임 재방문은 약 12–16ms였다. 새 이미지가 준비되거나 캐시가 교체되면 일부 그림은 다시 합성한다. 모든 상황의 지연이 제거됐다고 해석하지 않는다.

### 기능·저장·그림 검증

- 로그인된 상태로 서비스 홈과 숲을 왕복했고 로그인 유지가 확인됐다. 측정 종료 후 숲의 기본 장면으로 돌아왔으며 열린 대화상자는 닫았다.
- 옷장/창고 반복 검사에서는 저장 문자열이 변경되지 않았다. 저장하지 않는 항목 미리보기 검사에서도 재화·실제 착용 의상은 변경되지 않았다. 추가 재진입 검사에서 재화·의상·코디·창고·가구·퀘스트·보상·먹이 횟수 필드 변경이 없었다.
- 설치 직전과 최종 저장 해시를 비교하면 당근 1개 차감·먹이 횟수 1회 증가만 반영된 상태가 일치했다. 이는 먹이주기 카운터 변화와 일치하며 다른 비교 필드는 보존됐다. 이 값을 되돌리거나 데이터를 초기화하지 않았다.
- 저장 코디 6개의 캐시 그림을 기존 직접 합성과 비교한 결과 모든 픽셀 채널이 동일했다. 꾸미기/저장 코디의 실제 화면도 확인했다.
- 추가 회귀 테스트 7개 통과. 숲 JavaScript 전체 383개 중 382개, 숲 Python 계약 57개, 모바일 테스트 15개 통과. JavaScript의 나머지 1개는 기존 고양이 팩의 `.gitignore` 등록 검사 실패로, 이번 변경과 독립적이다. `git diff --check`도 통과했다.
- 최종 APK의 웹 파일이 생성된 로컬 번들과 일치하고 기존 설치본과 서명이 동일함을 확인했다. S25에 업데이트 설치했으며 커밋·푸시는 하지 않았다.
