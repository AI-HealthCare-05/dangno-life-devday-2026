# 당근의 숲 먹이주기 갱신 최적화

## 변경 내용

- 먹이주기는 기존 조건 확인 후 당근 1개 차감, 누적 먹이 횟수 저장, 잔액 표시와 펫 반응만 갱신한다. 닫힌 옷장·모임·창고 및 전체 지도 렌더링을 호출하지 않는다.
- 저장의 기본 동작은 기존처럼 전체 상태를 전달한다. 먹이주기에만 `persist(message, { syncScene: false })`를 사용해 불필요한 `forest-state-updated` 전달을 생략한다.
- 배치 정보가 동일하면 기존 Phaser 가구 객체를 유지한다. 위치·활성 상태·순서 등 실제 배치 정보가 바뀌면 기존 동물의 일시적 상태 복원 절차를 유지하면서 다시 구성한다.
- 아바타의 동일한 프레임은 합성 캔버스와 텍스처를 그대로 사용한다. 의상·방향·동작·실제 프레임 및 이미지 로딩 상태가 바뀌면 다시 그린다. 크기 조절은 매번 적용한다.
- 투명 영역 경계는 프레임 키별로 최대 64개만 보관한다. 픽셀 배열이나 추가 이미지 캔버스를 보관하지 않는다. 이미지가 추가로 로딩되면 키가 변경되어 최초 부분 로딩 그림이 캐시에 고정되지 않는다. 장면을 다시 만들 때 캐시를 초기화한다.

## 기준 측정

S25 로컬 앱에서 사용자 먹이주기 3회: 처리 완료 평균 약 1,953ms, 다음 애니메이션 프레임까지 평균 약 2,273ms. 대부분은 먹이주기 이벤트 안의 전체 화면 갱신에서 소요됐다. 해당 측정의 가구 동기화 시간은 0ms였으므로 가구 재생성을 당시 지연의 주원인으로 해석하지 않는다.

변경 후 실제 터치 응답 시간은 같은 휴대폰에서 추가 측정해야 한다. 단위 테스트의 실행 시간을 실기기 반응 시간으로 대신하지 않는다.

## 검증

`tests/forest-feed-performance.test.cjs`에서 차감·저장·펫 이벤트·전체 갱신 생략, 잔액 부족과 연속 입력, 가구 재사용과 실제 변경 반영, 프레임 재사용·이미지 로딩 후 무효화·64개 경계 캐시 제한을 검증한다. 기존 펫 반응·가구 움직임·앉기·의상·동작 및 모바일 패키징 테스트도 함께 실행한다.

기존 숲 전체 테스트 중 고양이 팩의 `.gitignore` 등록 확인은 현재 HEAD에도 등록이 없어 실패한다. 먹이주기 변경과 독립적인 기존 문제이며 별도로 기록한다.

2026-10-09 검증: 숲 전체 JavaScript 테스트 375개 중 374개 통과(위 기존 검사 1개 실패), 기존 숲 Python 계약 테스트 57개 및 모바일 패키징 테스트 15개 통과. 추가된 먹이주기 회귀 테스트는 별도로 실행했다.

S25의 `life.dangno.app`에 로컬 수정본을 업데이트 설치했다. API 주소는 `http://127.0.0.1:8000`이다. 휴대폰의 기존 APK에서 네이티브 코드를 유지하고 로컬 프런트엔드 번들을 교체해 정렬·서명했다. 기존 설치본과 인증서가 동일함을 확인했고, 새 APK의 세 수정 파일이 생성된 번들과 일치함을 확인했다. 이번 검증 패키지는 Gradle 전체 재빌드 결과가 아니다. 별도 배포 앱과 저장된 사용자 데이터는 변경하지 않았다.
