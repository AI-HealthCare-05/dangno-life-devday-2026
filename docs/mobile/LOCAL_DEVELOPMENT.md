## 현재 실행 구성

- Python 3.13 전용 `.venv`, Node/pnpm 모바일 앱 빌드 환경.
- 웹/API: http://127.0.0.1:8000 , API 문서: http://127.0.0.1:8000/api/docs .
- 별도 DB: `storage/local_mobile.sqlite3`. 기존 서버 계정·DB를 가져오지 않았으므로 앱에서 로컬 계정을 새로 가입한다. 테스트 정보만 입력한다.
- 비밀키는 무작위 생성 후 Git 제외 파일 `.env.local-mobile`에 저장한다. 운영 API 키나 원래 `.env`를 복사하지 않았다.
- `DEMO_MODE=true`는 SQLite와 내장 작업 실행을 위한 설정이다. `DEMO_ARTIFACT_INFERENCE_ENABLED=true`, `PREDICTION_PROVIDER=artifact`로 오늘이·내일이는 checksum을 검증한 실제 승인 모델 두 개를 사용한다. 예측 미리보기는 앱 복사본에서 비활성화했다.
- 음식 인식 모델도 지정된 Google Drive에서 내려받아 체크섬 검증 후 준비했다. Windows CPU용 PyTorch·timm·LiteRT를 설치했으며 `/api/v1/ready`는 200과 `food_vision_ready=true`를 반환한다. 외부 OCR·지도·메일 키와 자동 OpenAI VLM 보완은 설정하지 않았다.

## 서버 시작·종료

모든 명령을 이 복제본 루트에서 실행한다.

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File scripts/start-local-mobile.ps1
powershell.exe -NoProfile -ExecutionPolicy Bypass -File scripts/stop-local-mobile.ps1
```

서버는 숨김 실행한다. 로그는 `outputs/local-server.log`, `outputs/local-server.error.log`에 저장한다. app/src/ai_worker/scripts의 Python 수정은 자동으로 다시 로드된다. 웹 페이지 수정은 새로고침으로 확인한다. 서버 로그는 개발용으로만 사용하며 개인정보를 공유하지 않는다.

### Windows 네이티브 의존성 차단 복구 (2026-10-06)

- 가상환경 실행기는 시작되지만 SciPy `_ellip_harm_2`를 불러올 때 Smart App Control에 차단되는 경우를 확인했다. 실행기 시작 실패만 처리하던 기존 예외 경로로는 서버 시작 이후의 DLL 차단을 처리할 수 없었다.
- `start-local-mobile.ps1`은 로컬에 준비된 공식 Python 3.13.15 실행기가 있으면 Python Software Foundation의 유효한 서명을 확인한 후 우선 사용한다. 기존 `.venv` 의존성, 환경변수, 모델과 데이터베이스는 그대로 사용한다. 서명 검증 실패 시 서버를 시작하지 않는다.
- 공식 실행기의 SciPy 가져오기, 시작 스크립트 문법 검사, 수정된 스크립트를 통한 서버 재시작, `/health`와 `/api/v1/ready` 정상 응답 및 BlueStacks ADB reverse 연결을 확인했다. Windows 보안 정책이나 백신 예외는 변경하지 않았다.

환경 재설치가 필요하면 Python 3.13으로 `.venv`를 만들고 `requirements-local-mobile.txt`를 설치한다. 승인 모델 파일은 Git에서 제외되어 있으므로 기존 프로젝트의 같은 경로에서 가져오거나 공식 배포 절차를 따른다. 원본 의료 데이터는 필요하지 않다.

## BlueStacks 연결

BlueStacks 설정에서 Android 디버그 브리지(ADB)를 켠다. 현재 기기는 `127.0.0.1:5555`이며 로컬 APK는 `http://127.0.0.1:8000` API를 사용한다. ADB reverse가 에뮬레이터의 8000 포트를 PC의 8000 포트로 전달한다. 서버는 PC loopback에만 바인딩한다.

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File scripts/connect-bluestacks.ps1
```

재부팅·BlueStacks 재실행 후 위 연결 명령을 다시 실행한다. APK 재설치가 필요하면 `-Install`을 덧붙인다. 다른 ADB 경로는 환경변수 `MOBILE_ADB`로 지정할 수 있다.

바탕화면 **간당간당 로컬 앱 연결** 바로가기는 서버 시작·응답 확인·BlueStacks 포트 연결·앱 열기를 함께 수행한다. BlueStacks를 먼저 켠 뒤 실행한다. 이미 실행 중인 서버도 재사용하며 앱을 강제 종료하지 않는다.

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File scripts/start-local-app.ps1
```

회원가입 화면에서 연결 오류가 나면 이 바로가기로 포트 연결을 복구한 뒤 다시 제출한다. BlueStacks 재시작 시 ADB reverse가 사라질 수 있다. 2026-09-30 실제 앱 요청으로 임시 계정 회원가입 HTTP 201을 확인하고 해당 테스트 계정은 삭제했다. 입력 중인 사용자 폼은 변경하지 않았다. 개발용 WebView 연결 후 `node scripts/mobile/check-local-signup.mjs`로 이 검증을 재현할 수 있다.

오늘이·내일이는 기존 Drive 배포 계약을 그대로 사용한다. CV는 폴더에 있는 `best.pt`, `meta.json`, `1.tflite`의 파일 ID를 `configs/model_delivery/google_drive_cv.json`에 기록하고 기존 Registry의 SHA-256으로 검증한다. CV 파일 세 개를 모두 검증한 후 원자적으로 배치하며 하나라도 다르면 교체하지 않는다. 모델을 임의로 갱신하거나 등록된 해시를 자동으로 바꾸지 않는다.

모델 바이너리는 `models/artifacts/` 아래에 저장하며 Git에서 제외한다. 분석 요청마다 Drive에서 내려받지 않는다. VLM API를 사용하지 않아 테스트 사진을 외부 AI로 전송하지 않는다.

검증 결과: 저장소 테스트 사진 두 장의 실제 CV 추론 성공. `vegetable-meal-1.png`는 `valid`, `vegetable-meal-low-veg.png`는 `invalid_vegetable_ratio`. 기록은 Git 제외 `outputs/cv-smoke.json`에 있다. 이 판정은 영양소·섭취량·진단·치료를 추정하지 않는다.

`scripts/mobile/check-local.mjs`는 앱의 개발용 WebView를 9222에 전달한 뒤 연결 검증에 사용한다. 현재 실행 중인 WebView PID는 앱 재시작마다 바뀌므로 ADB forward 대상을 다시 지정해야 한다. 확인 후 개발용 forward는 제거한다.

## 숲 조이스틱 (2026-09-30)

기존 방향 버튼을 반투명 슬라이드 조이스틱으로 교체했다. 조이스틱은 방향만 제어하며 중심의 작은 유격을 넘으면 이동 속도가 일정하다. 대각선도 같은 속도로 이동한다. 달리기 버튼 또는 R 키로 걷기/달리기를 토글하며 버튼의 눌림 상태와 색상으로 구분한다. 미는 거리에 따른 속도 조절은 제공하지 않는다.

포인터를 놓거나 취소·캡처 해제·앱 비활성화·조작판 숨기기 시 즉시 이동 입력을 지운다. 점프/상호작용/달리기/앉기/공격은 별도 원형 버튼으로 배치했다. 키보드 이동과 게임 충돌 판정은 기존 경로를 사용한다. Phaser 초기화가 실패하면 기존 Canvas 이동으로 연결한다.

`node scripts/mobile/check-forest-render.mjs`에서 390/720px 조이스틱 방향, 작은/큰 기울기 동일 속도, 놓기/비활성화 정지, 달리기 두 번 토글, 손잡이 및 액션 버튼 표시를 확인한다.


숲 상단 사용자 이름은 표시용으로 바꾸고 `/service?account=profile`로 이동하던 클릭 처리를 제거했다. `check-forest-render.mjs`에서 이름 박스 클릭 후 URL과 숲 화면이 유지되는지 확인한다. 개인정보 수정 화면은 기존 서비스의 마이페이지에서 이용한다.
