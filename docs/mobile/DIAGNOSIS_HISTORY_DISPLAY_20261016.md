# 당뇨병 진단 기록의 건강정보 표시

당뇨병 진단으로 저장하거나 기존 건강정보를 진단 응답으로 수정하면, 내역에는 진단 카드만 표시한다. 같은 날짜의 건강정보 및 진단에 연결된 `source_checkup_id`의 측정 카드·수치·분석 보기 링크는 렌더링하지 않는다. 내역 건수와 페이지 나누기도 표시 대상만 기준으로 계산한다. 메인·인트로 화면에 동일하게 적용한다.

원래 건강정보를 서버에서 삭제하지는 않는다. 진단 내역의 다시 기록·삭제 기능에서 연결 정보를 유지하고, 진단 기록을 삭제하면 서버에서 허용되는 기존 건강정보가 다시 내역에 나타난다. 다른 날짜의 건강정보는 그대로 표시한다. 예측·분석 비활성화 정책은 유지한다.

기록 카드, 제목 행, 건강정보 영역, 원형 화살표 배경을 흰색으로 통일한다. 화살표는 선택된 원형·굵은 녹색 디자인을 유지하고, 마우스를 올려도 배경은 흰색으로 유지한다. 상태 배지는 기존 색상을 사용한다.

관련 검증:
- `tests/frontend/diagnosis_records.test.cjs`: 메인·인트로의 날짜/연결 ID에 따른 건강정보 숨김, 건수, 다른 날짜 표시, 진단 삭제 후 복원 및 원본 상태 보존.
- `scripts/mobile/check-diagnosis-guidance.mjs`: 합성 건강정보·진단 기록을 이용한 중복 카드/수치 제거, 흰색 배경, 4개 화면 너비 × 기본/큰 글자 및 펼침·접힘 검증.

검증 결과: 진단 내역·건강정보 관리·뒤로가기 관련 Node 테스트 39개 및 브라우저 시나리오 9개 통과. 블루스택 로컬 패키지 `life.dangno.app`에 기존 데이터 유지 업데이트 후 실행했다(2026-10-16 16:12:46). 설치 APK와 빌드 APK의 SHA-256은 `eba6c5929867d722fe277770f6e4662c25708de3eb547b5527ff413efd695079`로 일치한다. 로컬 서버 연결·DB 정상 응답을 확인했다. 배포 버전은 변경하지 않았다.
