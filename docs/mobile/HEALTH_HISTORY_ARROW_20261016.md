# 건강정보 기록 펼침·접힘 표시

사용자가 선택한 첫 번째 ‘원형’ 후보를 로컬 메인·인트로 화면의 공통 기록 스타일에 적용했다.

- 기존 문자 `⌄` / `^`를 둥근 끝의 굵기 3.5 SVG 화살표로 바꿨다.
- 원형 표시를 44×44px로 키우고 녹색 테두리·화살표를 사용한다. 후속 요청으로 원형과 기록 카드 배경은 흰색으로 통일했다.
- 펼침 상태에서는 위쪽, 접힘 상태에서는 아래쪽을 가리킨다. 모션 감소 설정에서는 회전을 즉시 반영한다.
- 별도 버튼을 추가하지 않고 기존 `details` / `summary`의 클릭·키보드 동작을 유지한다. 기록 수정·삭제 동작도 유지한다.
- 공통 `health-diagnosis.css`와 `assets/health-history-chevron.svg`를 사용한다. 두 진입 페이지의 스타일 캐시 버전을 갱신했다.

검증: `scripts/mobile/check-diagnosis-guidance.mjs`에서 320·390·720·1024px × 기본/큰 글자 크기별 원형 표시 크기·SVG 경로·키보드 펼침/접힘을 확인한다. 합성 기록만 사용하며 실제 이용자 기록은 변경하지 않는다.

9개 브라우저 시나리오를 통과했다. 로컬 APK에 SVG가 포함되었음을 확인하고, 블루스택의 `life.dangno.app`에 데이터 유지 업데이트를 수행했다(2026-10-16 16:04:51). 설치 해시: `fd4212149f70526caa82e73f99a65d980523c66525f263ff287893c30db88744`. 8000번 로컬 서버 연결도 복구했다. 배포 앱·서버는 이번 적용에 포함하지 않는다.
