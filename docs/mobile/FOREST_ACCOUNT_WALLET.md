# 당근의 숲 계정 지갑과 챌린지 보상

2026-10-09. 로컬 개발 변경 사항이며 운영 서버 배포 여부와 구분한다.

## 지급 정책

- `UserWallet`이 유일한 잔액 기준이다. 숲 상단, `/wallet`, 숲 API와 챌린지 응답은 같은 계정 잔액을 사용한다.
- 처음 숲/지갑을 사용하는 계정에 100개를 한 번 지급한다.
- 서버에서 완료된 음료·식단·운동 챌린지는 분야별로 하루 10개를 지급한다. 식단 안내는 “당근밭에 비료를 주었습니다”, 운동 안내는 “당근밭의 잡초를 뽑았습니다”이다.
- 하루 배정된 챌린지를 모두 완료하면 50개를 추가 지급한다. 표준 3개 계획은 총 80개다. 보상 상자를 열거나 밭을 수확하는 UI는 당근을 추가 지급하지 않는다.
- 기본 서비스 화면과 인트로 다시보기 화면 모두 서버가 반환한 보상 안내를 표시한다. 사진 검토가 대기 중이면 보상 안내를 표시하지 않는다.
- 서비스 챌린지 V3와 숲 챌린지 V2는 `challenge-domain:<user>:<KST date>:<domain>` 및 `challenge-daily:<user>:<KST date>` 키를 공유한다. 다른 화면에서 재인증하거나 챌린지를 변경해도 같은 날짜·분야의 보상은 추가 지급하지 않는다.
- 사진이 필요한 챌린지는 제출/검토 조건을 모두 충족해야 완료된다. 서버 오류·검토 대기·재제출 상태에서 로컬 완료와 보상을 생성하지 않는다.
- 기존 숲 활동은 물주기 +10/일, 첫 낚시 +5/일, 토끼 포획 +1/포획, 쥐 포획 0, 펫 먹이 -1/회다. 서버가 고정 금액을 결정하며 클라이언트가 금액을 지정할 수 없다.
- 활동은 `POST /api/v1/forest/wallet/actions`에 인증 토큰, 고정 `action`, UUID `request_id`를 보낸다. 하루 활동은 KST 날짜로 중복을 막고 포획·먹이는 동일 요청 UUID의 재전송을 중복 처리하지 않는다. 계정 간 키도 분리된다.
- 물주기·낚시·포획은 현재 클라이언트 게임이 수행 사실을 보고하는 구조다. 요청 중복 방지는 적용되지만 서버가 게임 위치·이동·동물 출현 자체를 검증하는 부정 플레이 방지 기능까지 구현한 것은 아니다.

## 저장 및 기존 계정 이관

- 잔액과 지급/차감 영수증은 같은 DB 트랜잭션으로 저장한다. 지갑 잠금 후 중복 키와 잔액을 확인하며 잔액 부족이나 영수증 저장 실패 시 모두 취소한다. 가구 생성과 차감도 함께 취소한다.
- `ForestAvatar.carrot_balance`는 기존 데이터 이관용 필드로 남으며 새 보상을 기록하지 않는다. 기존 welcome 이관에 포함된 보상은 재지급하지 않는다. welcome 이후 아바타에만 저장된 V2 지급 기록은 한 번 지갑에 반영한다. 공유 보상 키를 예약해 이관 후 재인증도 막는다.
- 기존 55개 일일 보상을 이미 받은 기록은 그대로 보존한다. 새로운 일일 보너스는 50개이며 기존 지급에 추가로 지급하지 않는다.
- 브라우저의 예전 체험 잔액·미수확 보상은 조작 가능한 값이므로 서버 지갑에 합산하지 않는다. 예전 원본 저장 데이터는 삭제하지 않는다. 코디·프리셋·배치는 보존하면서 계정별 저장 키로 분리한다. 계정 저장에는 잔액과 미검증 보상 값을 쓰지 않는다.
- 새 지갑 응답의 지급 기록 번호(`wallet_revision`)로 오래된 응답이 최신 잔액을 덮어쓰지 않게 한다. 화면 재활성화 시 서버 잔액을 갱신한다.
- DB 스키마 추가는 없으며 기존 테이블을 사용한다. 이관은 최초 지갑/숲 조회의 서버 트랜잭션 안에서 수행한다.

## 쥐·토끼 출현 조건 (변경 없음)

`src/frontend/forest-phaser.js`의 `spawnRat`, `updateRat`, `dismissRat` 기준이다.

- 챌린지 완료 수, 건강 결과, 당근 잔액과 관계없이 숲 월드에서 시간에 따라 발생한다.
- 최초 등장 대기: 게임 타이머 기준 3.5~7초. 일반 출현은 쥐/토끼를 동일 확률로 무작위 선택한다.
- 출현 위치 후보는 `(374,286)`, `(420,420)`, `(540,330)`, `(650,365)`, `(690,445)`, `(355,470)`이다. 아바타와 110 월드 단위보다 멀리 있는 후보를 우선한다.
- 포획/제거 후 일반 다음 등장: 12~22초.
- 토끼는 15~23초 동안 등장한다. 놓친 토끼는 사라진 뒤 2.2~4.2초 후 다음 토끼가 강제로 등장하므로 장시간 놓치면 일반 50:50 비율과 달라진다.
- 쥐는 12~18초 뒤 사라지는 대신 제자리에 남아 춤추고 “쥐가 당근을 노리고 있습니다” 경고를 5.6초 간격으로 반복한다. 이 경고 자체로 당근을 차감하지 않는다.
- 집·밭 내부에서는 야생 동물 업데이트를 하지 않는다. 사진 촬영과 탈것 전환 중에는 상위 게임 업데이트가 일시 중지된다. 일반 메뉴 열기만으로는 동물 타이머가 중지되지 않는다.
- 직접 공격/클릭과 펫 자동 공격이 같은 포획을 중복 처리하지 않는다. 펫은 플레이어와 동물의 거리 92.5 미만에서 추격하고 동물과 거리 25 미만, 공격 간격 2.6초 조건에서 포획한다.

## 검증 및 실행

- 테스트는 실제 사용자 DB와 분리된 메모리 SQLite 및 브라우저/Node 모형으로 실행한다.
- 관련 테스트: `tests/test_forest_account_wallet.py`, `tests/test_challenge_v21.py`, `tests/test_challenge_v3_api.py`, `tests/forest-wallet.test.cjs`, `tests/frontend/challenge_wallet.test.cjs`, `tests/frontend/challenge_v3.test.cjs`, 기존 숲 포획·수확·펫 테스트.
- 백엔드와 웹/Capacitor 번들을 함께 갱신해야 한다. 새 APK만 기존 운영 서버에 설치하는 것으로는 새 지갑 API와 보상 정책이 적용되지 않는다.
- 로컬 번들: `pnpm build:mobile:local`, `pnpm exec cap sync android`, Gradle `:app:assembleDebug`. 로컬 API 연결 방법은 `ANDROID_DEVICE_GUIDE.md`를 따른다.
- 운영 서버 배포, Git 커밋·푸시, 실제 사용자 데이터를 이용한 인증은 이 변경의 자동 검증에 포함하지 않는다.
