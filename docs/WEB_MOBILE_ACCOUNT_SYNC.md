# 웹·모바일 계정 연동

웹과 Android 체험 앱은 https://www.dang-no.life 의 같은 회원 API와 데이터베이스를 사용한다. 기존 이메일·비밀번호로 각 기기에서 로그인하며 프로필·건강정보·챌린지는 서버에서 조회한다. 기기 간 로그인 토큰을 전달하거나 로컬 저장소를 공유하지 않는다.

웹에 Android 앱과 동일한 auth-session 모듈을 적용했다. 같은 탭의 페이지 이동/새로고침에서 만료 전 토큰을 복원하되 users/me API로 검증한다. 토큰이 없거나 만료되면 서버의 refresh 쿠키로 복원을 시도한다. 쿠키가 없는 모바일 새 세션은 다시 로그인해야 한다. 로그아웃·계정 전환·인증 만료 처리에서는 저장 토큰을 제거한다.

#16은 다운로드 화면 변경으로 이미 병합됐다. 이 수정은 후속 PR이며 기존 APK 빌드의 네트워크 모듈은 API 경로만 AWS origin으로 연결하고 credentials=include를 적용한다. APK 고정 소스에는 동일 auth-session 모듈이 포함되어 있어 이번 변경은 웹의 복원 방식을 맞춘다.

iOS 서명 배포 및 실제 휴대폰 설치·동기화는 이번 코드 검사만으로 완료를 주장하지 않는다. 로그인은 각 기기에서 수행하고 같은 계정 서버 데이터가 표시되는지 실기기에서 확인해야 한다.
